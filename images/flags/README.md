# Community flags

Self-hosted 4:3 SVG artwork from [flag-icons](https://github.com/lipis/flag-icons), downloaded 28 September 2026. MIT license retained in LICENSE.txt. Only the 51 flags used by the homepage community section are included. Original SVGs are retained as sources. The website serves 192 × 144 lossless WebP derivatives (about 90 KB for all 51 combined); there is no library or remote request at runtime.

The country names remain visible HTML and the flags have empty alt text to avoid duplicate announcements.
