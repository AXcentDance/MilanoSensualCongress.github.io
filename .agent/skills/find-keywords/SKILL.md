# Keyword research

Prioritize qualified visitors and ticket sales for Milano Sensual Congress.
Inspect existing pages before proposing another URL. Use current search results
and available Search Console data; distinguish measured volume/rankings from
qualitative judgment. Never invent demand, difficulty, conversion percentages,
ranking timelines, or guarantees.

Map each distinct visitor intent to the most relevant current page. Extend a
page when it already answers that intent; propose a new one when it adds useful
information. Overlapping words alone do not prove cannibalization.

Use natural English and Italian, including accurate Bachata congress, workshop,
festival, Milan, Italy, and travel context where relevant. Do not force several
keywords into every title, H1, description, or image alt. Do not use density or
minimum word-count quotas.

Return a concise table of intent, language, target page, evidence, and priority,
with dated sources and clear uncertainty. Apply content changes only within the
user's task; follow the news/schema/index skills when implementing them.
